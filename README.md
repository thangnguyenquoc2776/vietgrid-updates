# VietGrid Updates

Signed native compatibility updates for OneNote desktop on Windows x64. Preview: Office 16.0.20527.20196 tested on one machine. Auto-update deployment is being validated. Each Office hash has its own release. New Office builds still require a compatible release to be published.

No Office DLL/PDB, notebooks, backups, sandbox IDs or private signing keys are published. MinHook/HDE license notices accompany each release.
